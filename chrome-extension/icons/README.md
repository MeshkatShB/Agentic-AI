# Extension Icons

You need to create the following icon files:

- `icon16.png` - 16x16 pixels (toolbar icon)
- `icon48.png` - 48x48 pixels (extension management page)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Creating Icons

You can:

1. Use any image editor (Photoshop, GIMP, etc.)
2. Use online tools like:
   - https://www.favicon-generator.org/
   - https://realfavicongenerator.net/
3. Create simple icons with text/emoji

## Icon Design Tips

- Use a simple, recognizable design
- Ensure icons are readable at small sizes
- Use high contrast colors
- Consider using your AI agent's branding colors

## Quick Start

For testing, you can create simple colored squares:

- Create 16x16, 48x48, and 128x128 pixel images
- Fill with a solid color (e.g., purple #8b5cf6)
- Save as PNG files with the names above
